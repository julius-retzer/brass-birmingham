# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase UI Scope: NONE

Phase 1 (Game Engine) has **zero UI requirements**. All 10 requirements (ENGINE-01 through ENGINE-10) are pure game logic: XState state machine correctness, scoring algorithms, era transitions, action validation, and test coverage. No screens, components, or visual elements are built or modified in this phase.

The roadmap explicitly sequences UI work into Phase 2 (Board and State Display) and Phase 3 (Playable Game).

**Consequence:** All design contract sections below are populated with the existing project defaults detected from the codebase. They serve as a baseline reference for Phase 2 and Phase 3 UI-SPECs, not as implementation targets for Phase 1.
