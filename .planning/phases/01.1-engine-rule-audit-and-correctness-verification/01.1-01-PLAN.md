  <action>
    Systematically audit every data file against the Brass Birmingham rulebook. For each data element:

    1. Read the rulebook section that defines the value (tile costs, slot types, connections, etc.)
    2. Read the corresponding data file value
    3. Compare and assign status: PASS (matches + has test), FAIL (wrong value), MISSING (no test evidence)
    4. Record the test file:line that proves correctness, or "-- " if no test exists

    **Industry tiles (src/data/industryTiles.ts):**
    - For each of the 6 industry types (CottonMill, CoalMine, IronWorks, Manufacturer, Pottery, Brewery):
      - Verify each level's cost (money, coal, iron) matches rulebook
      - Verify each level's VP and link points match rulebook
      - Verify era restrictions (canal-only, rail-only, both)
      - Verify flip conditions (beer requirement, auto-flip for coal/iron)
      - Verify hasLightbulbIcon on Pottery level 5 (cannot be developed)
    - Rule ref prefix: DATA-TILE-XX

    **Board locations (src/data/board.ts):**
    - Verify all 20 cities have correct industry slot types (which industries allowed in each slot)
    - Verify 2 farm breweries exist with brewery-only slots
    - Verify all connections have correct era types (canal, rail, or both)
    - Verify farm brewery connections model (implicit connection via Kidderminster-Worcester and Cannock-Walsall links)
    - Verify merchant locations are correctly placed
    - Rule ref prefix: DATA-BOARD-XX

    **Cards (src/data/cards.ts):**
    - Verify 2-player deck composition (which location cards, which industry cards, how many wild cards)
    - Verify card removal rules for 2-player setup (rulebook specifies which cards to remove)
    - Rule ref prefix: DATA-CARD-XX

    **Merchants (src/data/merchants.ts):**
    - Verify merchant count and placement per player count
    - Verify accepted industry types per merchant (investigate if all merchants really accept cotton/manufacturer/pottery or if they differ)
    - Verify VP bonus values (currently 2 for Nottingham and Shrewsbury -- verify this is correct)
    - Verify merchant bonus types (income, VP, develop, money)
    - When rulebook is ambiguous about merchant specifics, search BGG forums for clarification per D-03
    - Rule ref prefix: DATA-MERCH-XX

    **Output format (per D-07, D-08):**
    ```
    # Data Layer Audit

    **Audited:** {date}
    **Status values:** PASS = correct + tested | FAIL = incorrect | MISSING = untested or unimplemented

    ## Industry Tiles

    | Rule Ref | Rule Description | Status | Test Evidence | Notes |
    |----------|-----------------|--------|---------------|-------|
    | DATA-TILE-01 | CottonMill L1 costs 12 money, 0 coal, 0 iron | PASS | data.test.ts:42 | |
    ...

    ## Board Locations
    ...

    ## Cards
    ...

    ## Merchants
    ...

    ## Summary

    | Area | Total | PASS | FAIL | MISSING |
    |------|-------|------|------|---------|
    ```

    CRITICAL: When marking PASS, cite the exact test file and line number. "Tests exist" is not sufficient.
    CRITICAL: When the rulebook is ambiguous, note the ambiguity and any BGG/FAQ clarification found (D-03).
