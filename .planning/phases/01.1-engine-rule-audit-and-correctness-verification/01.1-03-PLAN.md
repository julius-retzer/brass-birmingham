    Audit all Build action rules. The Build action is the most complex action with ~20 sub-rules:

    **Card requirements:**
    - BUILD-01: Location card allows building at the named city only
    - BUILD-02: Industry card allows building the named industry type at any location in player's network
    - BUILD-03: Wild Location card allows building at any city in player's network (but NOT farm breweries -- verify this)
    - BUILD-04: Wild Industry card allows building any industry type
    - BUILD-05: One card must be discarded per build action

    **Location rules:**
    - BUILD-06: Can only build at locations that have a matching industry slot
    - BUILD-07: Canal era: max 1 industry tile per location per player
    - BUILD-08: Rail era: may place multiple tiles at same location
    - BUILD-09: Cannot build at a slot already occupied by another player's tile (unless overbuilding)
    - BUILD-10: Building with a location card does not require network connection
    - BUILD-11: Building with an industry card requires location to be in player's network

    **Cost and resource rules:**
    - BUILD-12: Must pay the money cost shown on the industry tile
    - BUILD-13: Must provide coal required (from board, connected sources, or market)
    - BUILD-14: Must provide iron required (from board or market -- iron has no network requirement)
    - BUILD-15: Coal consumed from nearest source first (network distance)
    - BUILD-16: Iron consumed from board first, then market

    **Overbuilding rules:**
    - BUILD-17: Can overbuild own tile (replace with higher level of same or different industry)
    - BUILD-18: Cannot overbuild opponent's tile
    - BUILD-19: Overbuilt tile must be same location
    - BUILD-20: Overbuilt tile is returned to player mat (or removed from game?)

    **Farm brewery rules:**
    - BUILD-21: Farm breweries can only contain Brewery tiles
    - BUILD-22: Farm breweries are connected to adjacent cities via link tiles placed between those cities
    - BUILD-23: Can only build at farm brewery using an industry card (Brewery), not a location card

    **Era-specific build rules:**
    - BUILD-24: Canal era: can only build level 1 tiles (or whatever the era restriction is)
    - BUILD-25: Rail era: must build at minimum the level shown on tile (level 1 tiles removed from game)

    For each rule: read the exact rulebook text, find the implementation in gameStore.ts and buildActions.ts, check for test evidence. When the rulebook is ambiguous (especially around overbuilding and farm breweries), search BGG for clarification per D-03.

    **Output format:** Standard audit table with BUILD-XX rule refs. Include a section header for each rule group (Card requirements, Location rules, Cost/resource, Overbuilding, Farm breweries, Era-specific).

    CRITICAL: Do NOT modify source code (D-06).
    CRITICAL: Cite exact test file:line for PASS verdicts.
    CRITICAL: Pay special attention to negative tests -- rules saying "cannot" or "must not" need tests that verify rejection.
