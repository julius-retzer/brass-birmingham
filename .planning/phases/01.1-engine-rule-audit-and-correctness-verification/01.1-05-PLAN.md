    **Canal era scoring rules:**
    - SCORE-01: Canal era ends when draw deck is empty and all players have used all actions
    - SCORE-02: Link VP: each canal link scores VP equal to the sum of VP icons on connected locations
    - SCORE-03: Industry VP: each flipped industry tile scores its VP value
    - SCORE-04: Unflipped tiles score 0 VP
    - SCORE-05: Link VP counts icons on BOTH ends of the link

    **Era transition rules (canal -> rail):**
    - ERA-01: All canal link tiles are removed from the board
    - ERA-02: All unflipped industry tiles are removed from the board (verify -- some rules say only level 1?)
    - ERA-03: Flipped industry tiles remain on the board
    - ERA-04: Level 1 industry tiles are removed from each player's mat (cannot be built in rail era)
    - ERA-05: Cards are reshuffled and re-dealt (8 cards each for 2 players)
    - ERA-06: Turn order for first round of rail era is determined by canal era spending
    - ERA-07: First round of rail era: each player gets 1 action (same as canal first round)
    - ERA-08: Player money, income, and VP carry over to rail era

    **Rail era scoring rules:**
    - SCORE-06: Rail era ends when draw deck is empty and all players have used all actions
    - SCORE-07: Link VP: each rail link scores VP (same formula as canal but for rail links)
    - SCORE-08: Industry VP: each flipped industry tile scores its VP value (includes tiles remaining from canal era)
    - SCORE-09: Total VP = canal link VP + canal industry VP + rail link VP + rail industry VP (verify formula)

    **End-of-game rules:**
    - END-01: Player with most VP wins
    - END-02: Tiebreaker 1: highest income level
    - END-03: Tiebreaker 2: (verify if there is a second tiebreaker)
    - END-04: Income is NOT converted to VP (per Phase 01-02 decision -- verify this matches rulebook)
    - END-05: Game result includes per-player breakdown: linkVP, industryVP, finalIncome, finalMoney

    For each rule: read rulebook, find implementation, check test evidence. Pay special attention to the known TODOs in gameStore.era.test.ts.
